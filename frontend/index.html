DevOps Deployment
Made Simple

A simple frontend application deployed inside an Apache HTTPD Docker container.

About This Project

This application is built as part of a DevOps project. The frontend is packaged into a Docker image using Apache HTTP Server.

Deployment Stack

Docker

Packages the frontend application into a portable container.

Apache HTTPD

Serves the frontend files from inside the Docker container.

AWS

The container can be deployed on an AWS EC2 instance.

Jenkins

Automates the infrastructure and deployment workflow.
